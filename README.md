## Structure

- **Spring 2024**
  - `CPSC_230` — Intro to Computer Science (Python)
  - `CPSC_298_C++` — C++ programming: pointers, inheritance, exceptions, linked lists
  - `CPSC_298_3DPrinting` — 3D modeling and printing (STL / G-code)
- **Fall 2024**
  - `Data Structures` — C++ projects and in-class work: linked lists, stacks, BSTs, heaps, hash maps, graphs
  - `Unity Programming` — C# game-programming patterns: commands, observer, state, singletons, coroutines
  - `Level Design` — board game design project
- **Spring 2025**
  - `Computer Architecture` — Logisim circuits (ALU, adders) and assembly labs

Each project folder has its own README describing how to build and run it.
